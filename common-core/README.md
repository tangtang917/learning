# common-core

## 模块目标
放少量公共结构，比如后续可能会复用的基础响应对象、异常基类、常量和工具类。

## 使用原则
- 只放真正公共的内容。
- 不要把业务逻辑塞进来。
- 新增公共类前先确认是否真的跨模块复用。

## 包结构说明
- `com.learning.common`：公共基础包，后续可以放通用返回对象、基础异常、常量、少量工具类。
- 当前先不细分子包，等出现明确复用场景后再拆分。
