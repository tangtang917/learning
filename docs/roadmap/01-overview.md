# 仓库总览

## 目标
这个仓库用于系统化学习 Java 后端开发，不追求一次性做出一个复杂业务系统，而是优先建立清晰、可复用、可复盘的知识结构。

## 设计原则
- 一个模块对应一个明确技能点。
- 基础练习模块尽量不依赖 Spring。
- 业务模块尽量只承载一个主题。
- 只有综合模块才把多种技术组合起来。
- 每个模块都有独立 `README.md` 作为资源和笔记入口。

## 学习方式
- 先文档后代码。
- 先单点再串联。
- 每周复盘一次，记录问题和结论。
- 每学完一个模块，都补一轮面试表述。

## 当前结构
- `playground-*` 负责语言、算法、并发、批量处理实验。
- `boot-*` 负责 Spring Boot 方向的技能演练。
- `ops-devtools` 负责环境和工程化。
