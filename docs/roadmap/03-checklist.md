# 学习检查清单

- [ ] 根工程和多模块结构可以看懂并维护
- [ ] 能说清每个模块的职责边界
- [ ] Java 基础练习覆盖集合、IO、反射、Lambda、Stream
- [ ] 算法模块形成固定刷题模板
- [ ] Spring Boot Web 模块能独立设计 REST API
- [ ] MySQL 和 MyBatis 模块能做事务、分页、SQL 排查
- [ ] Redis 模块能解释缓存穿透、击穿、雪崩和锁
- [ ] 并发模块能讲清线程池、锁、CompletableFuture
- [ ] 异步模块能完成进程内异步任务设计

- [ ] Pulsar 模块能完成生产消费和重试幂等演练
- [ ] 批量处理模块能完成分页批量处理和失败重试实验
- [ ] 综合模块能把多个技能点串起来
- [ ] 有每周复盘和面试话术沉淀
