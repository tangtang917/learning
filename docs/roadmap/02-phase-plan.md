# 阶段计划

## 第一阶段：语言与基础
- `playground-java-basics`
- `playground-algorithm`

目标：把 Java 语言、集合、IO、反射和常见算法框架打稳。

## 第二阶段：后端主线
- `boot-web`
- `boot-mybatis-mysql`
- `boot-redis`

目标：能独立写出带数据库和缓存的基础后端接口。

## 第三阶段：进阶能力
- `playground-jvm-concurrency`
- `boot-async-task`
- `boot-quartz-scheduler`
- `boot-mq-pulsar`
- `playground-batch-processing`

目标：把并发、异步、调度、消息队列、批量处理这些“像后端”的能力补齐。

## 第四阶段：综合练习与工程化
- `boot-integration-demo`
- `ops-devtools`

目标：把前面能力串成一个小型综合项目，并开始关注部署、脚本、日志和排障。
