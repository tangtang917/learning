# playground-jvm-concurrency

## 模块目标
练 JVM、线程基础、锁、线程池、CAS、AQS 和 `CompletableFuture`，建立对“异步和并发”这条后端主线的直觉。

## 学习范围
- JVM 内存、GC、类加载
- 线程与线程安全
- `synchronized`、`volatile`、`Lock`
- 线程池
- `CompletableFuture`
- CAS、AQS、并发容器
